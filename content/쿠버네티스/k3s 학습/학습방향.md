## 백엔드 개발자 기준 (운영 제외)

---

### 현실적인 기간: **4~6주**

매일 1~2시간 기준, Go 개발 경험 있고 Docker는 어느 정도 아는 상태 가정

---

## 주차별 로드맵

### 1주차 - 개념 + 클러스터 구성

```
- k3s 설치 (미니PC 3대 셋업)
- Pod / Node / Namespace 개념
- kubectl 기본 명령어 익히기
```

> 이 시점: "일단 뭔가 띄워진다"

---

### 2주차 - 핵심 리소스

```
- Deployment (배포, 롤링업데이트, 롤백)
- Service (ClusterIP, NodePort)
- ConfigMap / Secret
```

> 이 시점: Go 앱을 k8s에 올릴 수 있다

---

### 3주차 - 실전 배포 흐름

```
- Ingress + Traefik으로 도메인 라우팅
- PV/PVC로 데이터 영속성
- 헬스체크 (liveness, readiness probe)
- 네임스페이스로 환경 분리 (dev/prod)
```

> 이 시점: 실무랑 비슷한 흐름이 된다

---

### 4주차 - Helm

```
- Helm 차트 구조 이해
- 오픈소스 차트로 PostgreSQL, Redis 배포
- 직접 만든 Go 앱 Helm 차트 작성
```

> 이 시점: "그냥 가져다 쓸 수 있다"

---

### 5~6주차 - CI/CD 연결

```
- GitHub Actions → Docker 빌드 → k8s 자동 배포
- ArgoCD로 GitOps 맛보기
```

> 이 시점: 코드 푸시하면 자동으로 배포됨

---

## 솔직한 얘기

**빠른 사람은 2~3주**에 실무 수준 가능하고, **천천히 해도 2달** 안에 충분합니다.

제일 시간 잡아먹는 건 개념이 아니라 **yaml 오타, 네트워크 삽질, 이미지 안 올라가는 문제** 같은 것들이에요.

미니PC 3대 있으니까 환경은 완벽합니다. 실제로 띄워보면서 하는게 강의 10개 보는 것보다 빠릅니다.
