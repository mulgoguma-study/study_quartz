## 실전 팁

시험 환경이 **PSI 브라우저**라서, 시험 시작 전에 허용 탭을 미리 열어두는 게 좋아요.

```
시험 시작 직후 열어둘 탭:

1. kubernetes.io/docs/reference/kubectl/cheatsheet/
2. kubernetes.io/docs/concepts/configuration/secret/
3. kubernetes.io/docs/tasks/configure-pod-container/security-context/
4. kubernetes.io/docs/concepts/workloads/pods/
```

그리고 docs에서 찾을 때는 **브라우저 내 검색(Ctrl+F)**보다 **사이트 검색창**이 훨씬 빠릅니다. 예를 들어:

```
kubernetes.io 검색창에: "security context"
→ 예시 YAML 있는 페이지 바로 나옴
→ 복붙
```
