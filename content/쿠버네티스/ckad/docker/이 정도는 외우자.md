Go 백엔드 개발자 기준으로 **손에 익혀야 할 것들**만 추리면:

**자주 까먹는 것들 (근데 시험에 나옴)**

**멀티스테이지 빌드(Dockerfile 작성)**
```dockerfile
# 멀티스테이지 - Go는 이게 거의 필수 패턴
FROM golang:1.22 AS builder
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN go build -o server ./cmd/server

FROM alpine:latest          # 최종 이미지는 가볍게
COPY --from=builder /app/server .
CMD ["./server"]
```

**CKAD에서 나오는 docker 명령어 (이것만 외우면 됨)**

```bash
docker build -t myapp:v1 .   <- 자동으로 dockerfile 읽음
docker save myapp:v1 -o myapp.tar   # export 문제 자주 출제
docker load -i myapp.tar   # tar 파일저장된 이미지를 로컬 tar로 가져오는 명령어
docker tag myapp:v1 registry/myapp:v1 # 새 테그 붙이기
docker push registry/myapp:v1     # 태그 이미지를 원격 레지스트리에 업로드
```

사실 Go는 다른 언어보다 멀티스테이지 빌드가 **훨씬 자연스러운** 언어라서, 이미 프로젝트에서 `Dockerfile` 보셨으면 패턴 자체는 낯설지 않으실 거에요.
