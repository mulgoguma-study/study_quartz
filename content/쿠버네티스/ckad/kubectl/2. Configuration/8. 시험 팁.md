### 시작 세팅

bash

```bash
alias k=kubectl
export do="--dry-run=client -o yaml"
export now="--grace-period=0 --force"
```

### 자주 쓰는 YAML 생성 명령

#### ConfigMap

bash

```bash
# literal
k create cm app-config --from-literal=ENV=prod --from-literal=LOG=debug

# 파일에서
k create cm app-config --from-file=app.properties

# env 파일 (KEY=VALUE 형식)
k create cm app-config --from-env-file=config.env

# YAML로 출력
k create cm app-config --from-literal=ENV=prod $do > cm.yaml

# 조회
k get cm
k describe cm app-config
k get cm app-config -o yaml
```

#### Secret

bash

```bash
# literal
k create secret generic db-secret --from-literal=password=s3cr3t

# 파일에서
k create secret generic ssh-key --from-file=id_rsa

# TLS
k create secret tls my-tls --cert=server.crt --key=server.key

# Docker registry
k create secret docker-registry regcred \
  --docker-server=registry.io --docker-username=u --docker-password=p

# YAML로 출력
k create secret generic db-secret --from-literal=password=s3cr3t $do > sec.yaml

# 값 디코딩
k get secret db-secret -o jsonpath='{.data.password}' | base64 -d
```

#### Resources / SecurityContext

bash

```bash
# Resources
k set resources deploy/web \
  --requests=cpu=100m,memory=128Mi \
  --limits=cpu=500m,memory=512Mi

# Pod 생성 후 SecurityContext는 YAML 직접 작성
k run my-pod --image=nginx $do > pod.yaml
# vi pod.yaml로 securityContext 추가
```

#### ServiceAccount

bash

```bash
k create sa my-sa
k create sa my-sa -n dev

# Pod에 할당
k set serviceaccount deploy/web my-sa
# 또는 YAML에서 spec.serviceAccountName 추가

# 토큰 생성
k create token my-sa
```

#### Env 설정 (set env)

bash

```bash
# 환경변수 추가/변경
k set env deploy/web ENV=prod LOG_LEVEL=debug

# 환경변수 삭제
k set env deploy/web ENV-

# ConfigMap 전체를 env로
k set env deploy/web --from=configmap/app-config

# Secret 전체를 env로
k set env deploy/web --from=secret/db-secret

# Prefix 추가
k set env deploy/web --from=configmap/app-config --prefix=APP_

# 현재 env 확인
k set env deploy/web --list
```

### explain으로 확인할 필드

bash

```bash
# Resources
k explain pod.spec.containers.resources

# SecurityContext (필드 헷갈리므로 자주 확인)
k explain pod.spec.securityContext
k explain pod.spec.containers.securityContext
k explain pod.spec.containers.securityContext.capabilities

# Env / EnvFrom
k explain pod.spec.containers.env
k explain pod.spec.containers.envFrom
k explain pod.spec.containers.env.valueFrom --recursive

# Volume
k explain pod.spec.volumes.configMap
k explain pod.spec.volumes.secret
```
