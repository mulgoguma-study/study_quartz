애플리케이션 설정값을 Pod와 분리해서 관리합니다.

#### 생성 방법 (4가지)

bash

```bash
# 1. literal로 직접
k create cm app-config --from-literal=ENV=prod --from-literal=LOG_LEVEL=debug

# 2. 파일에서 (파일명이 key, 내용이 value)
k create cm app-config --from-file=app.properties
k create cm app-config --from-file=config1.txt --from-file=config2.txt

# 3. 디렉토리 전체
k create cm app-config --from-file=/path/to/configs/

# 4. env 파일 (KEY=VALUE 형식)
k create cm app-config --from-env-file=config.env
```

#### ConfigMap YAML

yaml

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
data:
  ENV: prod
  LOG_LEVEL: debug
  app.properties: |
    server.port=8080
    server.host=0.0.0.0
```

#### 사용 방법 3가지

**방법 1: 환경변수로 (특정 key만)**

yaml

```yaml
spec:
  containers:
  - name: app
    image: nginx
    env:
    - name: ENVIRONMENT
      valueFrom:
        configMapKeyRef:
          name: app-config
          key: ENV
```

**방법 2: 환경변수로 (전체)**

yaml

```yaml
spec:
  containers:
  - name: app
    image: nginx
    envFrom:
    - configMapRef:
        name: app-config
```

**방법 3: 볼륨으로 마운트 (파일로)**

yaml

```yaml
spec:
  containers:
  - name: app
    image: nginx
    volumeMounts:
    - name: config-vol
      mountPath: /etc/config
      readOnly: true
  volumes:
  - name: config-vol
    configMap:
      name: app-config
      # 특정 key만 마운트
      items:
      - key: app.properties
        path: application.properties
```

볼륨 마운트 시 `/etc/config/` 아래에 각 key가 파일명, value가 파일 내용으로 생성됩니다.
