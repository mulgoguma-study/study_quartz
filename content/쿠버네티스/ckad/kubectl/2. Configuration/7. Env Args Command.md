#### 모든 환경변수 주입 방식

yaml

```yaml
spec:
  containers:
  - name: app
    image: my-app
    env:
    # 1. 직접 값
    - name: ENV
      value: "prod"
    # 2. ConfigMap에서
    - name: APP_CONFIG
      valueFrom:
        configMapKeyRef:
          name: app-config
          key: config-key
    # 3. Secret에서
    - name: DB_PASSWORD
      valueFrom:
        secretKeyRef:
          name: db-secret
          key: password
    # 4. Pod 정보 (Downward API)
    - name: POD_NAME
      valueFrom:
        fieldRef:
          fieldPath: metadata.name
    # 5. 리소스 정보 (Downward API)
    - name: CPU_LIMIT
      valueFrom:
        resourceFieldRef:
          containerName: app
          resource: limits.cpu
    
    envFrom:
    # 6. ConfigMap 전체
    - configMapRef:
        name: app-config
    # 7. Secret 전체
    - secretRef:
        name: db-secret
    # 8. Prefix 추가
    - prefix: APP_
      configMapRef:
        name: app-config
```

#### Command / Args

yaml

```yaml
containers:
- name: app
  image: busybox
  command: ["sh", "-c"]                   # Docker ENTRYPOINT
  args: ["echo hello && sleep 3600"]      # Docker CMD
```

명령어로 생성:

bash

```bash
# args만 (이미지 ENTRYPOINT 사용)
k run my-pod --image=busybox $do -- sleep 3600 > pod.yaml

# command 지정
k run my-pod --image=busybox --command $do -- /bin/sh -c "sleep 3600" > pod.yaml
```
