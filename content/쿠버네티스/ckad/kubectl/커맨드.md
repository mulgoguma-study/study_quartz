# CKAD kubectl 핵심 정리

## 시험 시작 전 필수 세팅

```bash
alias k=kubectl
export do="--dry-run=client -o yaml"   # yaml 뽑을 때
export now="--force --grace-period 0"  # 빠른 삭제
source <(kubectl completion bash)
complete -F __start_kubectl k          # alias에도 자동완성 적용
```

---

## Pod

```bash
k run nginx --image=nginx                          # Pod 생성
k run nginx --image=nginx $do > pod.yaml           # yaml로 뽑기
k run nginx --image=nginx --env="KEY=VALUE"        # 환경변수
k run nginx --image=nginx --labels="app=web"       # 라벨
k run nginx --image=nginx --requests="cpu=100m,memory=128Mi"
k run nginx --image=nginx --limits="cpu=200m,memory=256Mi"
k exec -it nginx -- /bin/sh                        # 접속
k logs nginx                                       # 로그
k logs nginx -c container-name                     # 멀티컨테이너
k delete pod nginx $now                            # 빠른 삭제
```

## Deployment

```bash
k create deploy nginx --image=nginx --replicas=3
k create deploy nginx --image=nginx --replicas=3 $do > deploy.yaml
k scale deploy nginx --replicas=5
k set image deploy/nginx nginx=nginx:1.25
k rollout status deploy/nginx
k rollout history deploy/nginx
k rollout undo deploy/nginx
k rollout undo deploy/nginx --to-revision=2
```

## Service

```bash
k expose pod nginx --port=80 --target-port=8080 --name=svc-nginx
k expose deploy nginx --port=80 --type=NodePort
k create svc clusterip my-svc --tcp=80:8080
```

## ConfigMap / Secret

```bash
k create cm my-cm --from-literal=KEY=VALUE
k create cm my-cm --from-file=app.properties
k create secret generic my-secret --from-literal=password=1234
k create secret generic my-secret --from-env-file=.env
```

## Namespace

```bash

k get pods -n kube-system

```

## 자주 쓰는 조회/수정

```bash
k get pods -o wide                        # IP, 노드 정보
k get pods --show-labels
k get pods -l app=nginx                   # 라벨 필터
k describe pod nginx                      # 상세 정보
k edit pod nginx                          # 직접 수정
k apply -f manifest.yaml                  # 적용
k delete -f manifest.yaml
k top pod                                 # 리소스 사용량
k top node
```

## yaml 추출 패턴 (시험에서 제일 많이 씀)

```bash
# 없는 리소스 yaml 생성
k run nginx --image=nginx $do > pod.yaml

# 있는 리소스 yaml 추출
k get pod nginx -o yaml > pod.yaml

# 수정 후 적용
vi pod.yaml
k apply -f pod.yaml

# 또는 replace로 강제 적용
k replace -f pod.yaml --force
```

## CKAD 주요 시험 토픽별 키워드

| 토픽                       | 주요 필드                                       |
| ------------------------ | ------------------------------------------- |
| Multi-container Pod      | `initContainers`, sidecar 패턴                |
| ConfigMap/Secret 마운트     | `envFrom`, `volumeMounts`                   |
| Resource Limits          | `resources.requests/limits`                 |
| Liveness/Readiness Probe | `livenessProbe`, `readinessProbe`           |
| Security Context         | `securityContext.runAsUser`, `capabilities` |
| NetworkPolicy            | `podSelector`, `ingress/egress`             |
| PersistentVolume         | `PVC`, `storageClassName`                   |
| RBAC                     | `Role`, `RoleBinding`, `ClusterRole`        |
| Ingress                  | `ingressClassName`, `rules.host`            |

## 시험 꿀팁

- `k explain pod.spec.containers` — 필드 모를 때 바로 조회
- `k explain --recursive pod.spec` — 전체 구조 보기
- 공식 docs 북마크: `kubernetes.io/docs` (시험 중 열람 가능)
- yaml 직접 짜지 말고 **항상 `$do`로 뽑아서 수정**하는 습관
- 문제 배점 확인하고 어려운 건 넘기고 나중에 돌아오기
