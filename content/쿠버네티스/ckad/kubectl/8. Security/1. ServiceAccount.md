Pod이 Kubernetes API와 통신할 때 사용하는 신원입니다. 출제 빈도가 매우 높습니다.

```bash 
# 생성
kubectl create serviceaccount my-sa
kubectl create sa my-sa  # 축약형

# 토큰 생성 (1.24+ 이후 시험 환경)
kubectl create token my-sa
```

Pod에 할당하는 방법:
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: my-pod
spec:
  serviceAccountName: my-sa  # 이 한 줄이 핵심
  automountServiceAccountToken: false  # 가끔 비활성화 요구
  containers:
  - name: app
    image: nginx
```

**출제 패턴**: "특정 namespace에 SA를 만들고, Pod에 할당하라" — 거의 매 시험 변형으로 나옵니다.
