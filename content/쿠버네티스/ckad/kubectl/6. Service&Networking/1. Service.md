### 1. Service란

Pod은 일시적입니다. 죽었다 살아나면 IP가 바뀝니다. Service는 Pod 앞에 두는 **안정적인 네트워크 진입점**입니다.

```
Client → Service (고정 IP/DNS) → Pod1, Pod2, Pod3 (변동)
```

핵심 동작:

- 라벨 selector로 대상 Pod을 찾음
- 가상 IP(ClusterIP)와 DNS 이름 제공
- 트래픽을 Pod들에게 로드밸런싱

### 2. Service의 4가지 타입

#### ClusterIP (기본)

클러스터 **내부에서만** 접근 가능한 가상 IP. Pod 간 통신용.

yaml

```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-svc
spec:
  type: ClusterIP        # 생략하면 기본값
  selector:
    app: web
  ports:
  - port: 80             # Service의 포트
    targetPort: 8080     # Pod의 포트
    protocol: TCP
```

#### NodePort

각 노드의 특정 포트로 외부에서 접근 가능. 포트 범위 30000-32767.

yaml

```yaml
spec:
  type: NodePort
  selector:
    app: web
  ports:
  - port: 80             # ClusterIP 포트
    targetPort: 8080     # Pod 포트
    nodePort: 30080      # 노드 포트 (생략 시 자동 할당)
```

접근: `<NodeIP>:30080`

#### LoadBalancer

클라우드 환경에서 외부 로드밸런서를 자동 프로비저닝. 로컬 환경에서는 Pending 상태로 머무름.

yaml

```yaml
spec:
  type: LoadBalancer
  selector:
    app: web
  ports:
  - port: 80
    targetPort: 8080
```

#### ExternalName

외부 DNS 이름의 alias. selector 없음.

yaml

```yaml
spec:
  type: ExternalName
  externalName: api.example.com
```

`my-svc.default.svc.cluster.local`을 `api.example.com`으로 매핑.

#### Headless Service

`clusterIP: None`을 지정하면 가상 IP 없이 각 Pod의 IP를 DNS로 직접 반환. StatefulSet에 자주 사용.

yaml

```yaml
spec:
  clusterIP: None
  selector:
    app: db
  ports:
  - port: 5432
```

### 3. 포트 용어 정리

자주 헷갈리는 부분입니다.

yaml

```yaml
ports:
- port: 80          # Service가 노출하는 포트
  targetPort: 8080  # Pod 안 컨테이너의 포트
  nodePort: 30080   # 노드의 포트 (NodePort 타입만)
```

```
[ Client ]
   │
   ▼ nodePort (30080) ← 외부 접근
[ Node ]
   │
   ▼ port (80) ← Service 내부
[ Service ]
   │
   ▼ targetPort (8080) ← Pod 도착
[ Pod ]
```

### 4. Service의 DNS

Service는 자동으로 DNS 이름을 가집니다.

```
<service-name>.<namespace>.svc.cluster.local
```

예시:

- 같은 namespace: `my-svc`
- 다른 namespace: `my-svc.prod`
- 전체 FQDN: `my-svc.prod.svc.cluster.local`

### 5. Endpoints

Service가 어떤 Pod IP들을 가지고 있는지는 Endpoints 리소스에 기록됩니다.

bash

```bash
k get endpoints my-svc
k get ep my-svc           # 축약형
# NAME     ENDPOINTS                       AGE
# my-svc   10.244.0.5:8080,10.244.0.6:8080   1m
```

Endpoints가 비어있으면 selector가 잘못됐거나 매칭되는 Pod이 없는 것입니다.
