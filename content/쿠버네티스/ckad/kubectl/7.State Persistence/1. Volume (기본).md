emptyDir과 hostPath 정도는 알아두세요.

yaml

```yaml
spec:
  containers:
  - name: app
    image: nginx
    volumeMounts:
    - name: cache
      mountPath: /cache
  volumes:
  - name: cache
    emptyDir: {}              # Pod 생명주기와 동일
  # 또는
  - name: data
    hostPath:
      path: /data
      type: DirectoryOrCreate
```

emptyDir에 `medium: Memory`를 주면 tmpfs로 마운트되는 것도 가끔 나옵니다.
