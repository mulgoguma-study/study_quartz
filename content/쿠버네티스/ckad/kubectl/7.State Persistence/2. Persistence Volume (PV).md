```yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: pv-001
spec:
  capacity:
    storage: 1Gi
  accessModes:
  - ReadWriteOnce        # RWO
  persistentVolumeReclaimPolicy: Retain  # Retain / Delete / Recycle
  storageClassName: manual
  hostPath:
    path: /mnt/data
```

AccessMode 종류 (반드시 외우기):

- `ReadWriteOnce` (RWO): 한 노드에서 읽기/쓰기
- `ReadOnlyMany` (ROX): 여러 노드에서 읽기만
- `ReadWriteMany` (RWX): 여러 노드에서 읽기/쓰기
- `ReadWriteOncePod` (RWOP): 단일 Pod만

Reclaim Policy:

- `Retain`: 수동으로 회수
- `Delete`: 자동 삭제
- `Recycle`: deprecated
