
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: app-pod
spec:
  containers:
  - name: app
    image: nginx
    volumeMounts:
    - name: data
      mountPath: /usr/share/nginx/html
  volumes:
  - name: data
    persistentVolumeClaim:
      claimName: pvc-001
```

**출제 패턴**: "PV를 생성하고, PVC를 생성하고, Pod이 그 PVC를 마운트하게 하라. accessMode와 size를 정확히 맞춰야 바인딩됨." 거의 통째로 묶여서 나옵니다.
