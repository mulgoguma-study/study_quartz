### Context와 Config

`kubectl`이 어느 클러스터에 어떤 권한으로 접근하는지 설정.

bash

```bash
# 현재 컨텍스트
k config current-context

# 전체 설정 보기
k config view
k config view --minify             # 현재 컨텍스트만

# 컨텍스트 목록
k config get-contexts

# 컨텍스트 전환
k config use-context dev-cluster

# 현재 컨텍스트의 namespace 변경
k config set-context --current --namespace=dev
```

CKAD 시험은 단일 클러스터지만, 종종 namespace를 자주 바꿔야 해서 `set-context --current --namespace=X` 명령은 자주 씁니다.
