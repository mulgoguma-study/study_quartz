## Core Concepts 시험 팁

### 시작 세팅 (시험 시작 직후 첫 작업)


```bash
# 1. alias 설정
alias k=kubectl
export do="--dry-run=client -o yaml"
export now="--grace-period=0 --force"

# 2. 자동완성 활성화
source <(kubectl completion bash)
complete -F __start_kubectl k

# 3. vi 들여쓰기 설정
cat >> ~/.vimrc << EOF
set tabstop=2
set expandtab
set shiftwidth=2
EOF

# 4. 시험 namespace 확인
k config view --minify | grep namespace
```

이 5분 투자가 시험 내내 시간을 절약해줍니다.

### 자주 쓰는 명령 요약

#### 리소스 생성 (imperative)

```bash
# Pod
k run <name> --image=<img>
k run <name> --image=<img> --port=80 --env="K=V" --labels="app=web"
k run <name> --image=<img> --restart=Never $do > pod.yaml

# Deployment
k create deploy <name> --image=<img> --replicas=3
k create deploy <name> --image=<img> $do > deploy.yaml

# Service
k expose deploy <name> --port=80 --target-port=8080
k expose deploy <name> --port=80 --type=NodePort
k create svc clusterip <name> --tcp=80:8080

# Job / CronJob
k create job <name> --image=<img> -- <cmd>
k create cronjob <name> --image=<img> --schedule="*/1 * * * *" -- <cmd>

# Namespace
k create ns <name>

# ConfigMap / Secret
k create cm <name> --from-literal=K=V
k create secret generic <name> --from-literal=K=V

# ServiceAccount
k create sa <name>

# Role / RoleBinding
k create role <name> --verb=get,list --resource=pods
k create rolebinding <name> --role=<role> --serviceaccount=<ns>:<sa>

# Ingress
k create ingress <name> --rule="host/path*=svc:port"
```

#### 조회

```bash
# 기본 조회 패턴
k get <resource>
k get <resource> -A                # 모든 namespace
k get <resource> -n <ns>
k get <resource> -o wide
k get <resource> -o yaml
k get <resource> --show-labels
k get <resource> -l <selector>
k get <resource> --sort-by=<field>

# 자주 보는 조합
k get pod -o wide --show-labels
k get all
k get all -n <ns>
k get events --sort-by=.metadata.creationTimestamp
```

#### 수정

bash

```bash
# edit (대부분의 필드)
k edit deploy/web
k edit pod my-pod          # 거의 모든 필드 immutable

# 특정 필드 (set)
k set image deploy/web nginx=nginx:1.25
k set env deploy/web KEY=value
k set resources deploy/web --limits=cpu=500m
k set serviceaccount deploy/web my-sa

# 라벨/어노테이션
k label pod my-pod env=prod
k annotate pod my-pod owner=team-A

# scale
k scale deploy web --replicas=5
```

#### 삭제


```bash
k delete pod my-pod
k delete pod my-pod $now           # 즉시 (grace=0, force)
k delete deploy web
k delete -f deploy.yaml
k delete pods --all                # namespace의 모든 Pod
k delete pods -l app=web           # 라벨로
k delete ns dev                    # namespace 통째로 (안의 모든 리소스 삭제)
```

### explain으로 확인할 필드
```bash
# 가장 자주 쓰는 패턴
k explain pod
k explain pod.spec
k explain pod.spec.containers
k explain pod.spec.containers --recursive | less

# 다른 리소스
k explain deploy.spec
k explain svc.spec
k explain ingress.spec --recursive | less

# 필드 검색
k explain pod --recursive | grep -i <keyword>
```

**시험장에서 가장 유용한 도구**가 `explain`입니다. 필드명/구조 헷갈리면 무조건 explain.
