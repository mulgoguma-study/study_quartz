라벨은 리소스에 붙이는 key-value 태그입니다. Selector로 필터링과 그룹화의 기준이 됩니다.

#### 라벨 관리

bash

```bash
# 추가
k label pod my-pod env=prod
k label pod my-pod tier=front app=web   # 여러 개

# 수정 (--overwrite 필수)
k label pod my-pod env=dev --overwrite

# 삭제 (key 뒤에 -)
k label pod my-pod env-

# 모든 Pod에 라벨
k label pods --all tier=backend

# 라벨 표시
k get pods --show-labels
k get pods -L env,app           # 컬럼으로 표시
```

#### Selector 문법

bash

```bash
# Equality
k get pods -l app=web
k get pods -l env!=prod
k get pods -l app=web,env=prod          # 콤마는 AND

# Set-based
k get pods -l 'env in (prod,staging)'
k get pods -l 'env notin (dev)'
k get pods -l 'app'                     # app 라벨 존재
k get pods -l '!app'                    # app 라벨 없음

# 라벨로 삭제
k delete pods -l app=web
```

#### Annotations (라벨과 차이)

bash

```bash
k annotate pod my-pod description="web server"
k annotate pod my-pod owner="team-A"
k annotate pod my-pod description-     # 삭제
```

|항목|Labels|Annotations|
|---|---|---|
|용도|식별, 그룹화|메타데이터, 도구용|
|Selector|가능|불가|
|크기|작음|큼 가능|
|예시|`app=web`|`last-deployed-by: john`|
