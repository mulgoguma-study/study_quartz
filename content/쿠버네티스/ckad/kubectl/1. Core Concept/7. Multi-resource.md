### Multi-resource 작업

bash

```bash
# 여러 종류 한 번에
k get pod,svc,deploy
k get all                          # Pod, Service, Deployment, RS 등
k get all -n dev

# 여러 이름 한 번에
k delete pod pod1 pod2 pod3
k get pod pod1 pod2

# 파일로 일괄
k apply -f pod.yaml,svc.yaml
k apply -f ./manifests/
k apply -f https://example.com/manifest.yaml

# 라벨로 일괄
k delete pods -l app=web
k get all -l app=web
```
