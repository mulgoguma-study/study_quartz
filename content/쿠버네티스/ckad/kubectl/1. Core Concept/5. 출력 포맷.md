### 출력 포맷 (output formats)

bash

```bash
# 기본 (테이블)
k get pods

# 자세히
k get pods -o wide

# YAML / JSON
k get pod my-pod -o yaml
k get pod my-pod -o json

# 이름만
k get pods -o name

# JSONPath (특정 필드 추출)
k get pod my-pod -o jsonpath='{.status.podIP}'
k get pods -o jsonpath='{.items[*].metadata.name}'
k get pods -o jsonpath='{range .items[*]}{.metadata.name}{"\n"}{end}'

# 커스텀 컬럼
k get pods -o custom-columns=NAME:.metadata.name,IP:.status.podIP

# 정렬
k get pods --sort-by=.metadata.creationTimestamp
k get pods --sort-by=.status.podIP

# 다른 namespace
k get pods -A
```
