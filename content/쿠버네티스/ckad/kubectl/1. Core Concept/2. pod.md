### Pod (가장 기본 단위)

Pod의 자세한 내용은 별도 정리. 여기서는 Core 관점에서 핵심만.

yaml

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: my-pod
  labels:
    app: web
spec:
  containers:
  - name: app
    image: nginx
```

핵심 명령:

bash

```bash
# 생성
k run my-pod --image=nginx
k run my-pod --image=nginx $do > pod.yaml

# 조회
k get pod
k get pod -o wide              # IP, Node 포함
k get pod -o yaml              # 전체 YAML
k get pod my-pod -o jsonpath='{.status.podIP}'

# 삭제
k delete pod my-pod
k delete pod my-pod --grace-period=0 --force   # 즉시
```
