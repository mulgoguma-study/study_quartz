

설치 후 `using-superpowers` 마스터 스킬이 대화 시작 시 자동으로 실행되면서 요청에 맞는 스킬을 자동으로 라우팅해줘요. 개별 스킬을 수동으로 호출할 필요가 없어요.

**자동으로 따르는 5단계 흐름:**

```
clarify → design → plan → code → verify
```

**주요 슬래시 커맨드:**

|커맨드|역할|
|---|---|
|`/brainstorming`|코딩 전 요구사항 정리|
|`/execute-plan`|구현 플랜 실행|
|`/using-superpowers`|수동으로 마스터 스킬 활성화|

## gstack이랑 같이 쓰는 흐름

```
gstack /autoplan      # 기획
→ Superpowers 자동    # TDD 기반 구현
→ gstack /review      # 코드 리뷰
→ gstack /ship        # 배포
```

코딩 에이전트가 구현을 시작하면 먼저 스펙을 대화로 뽑아내고, 설계를 섹션별로 보여주고 확인받은 후, 구현 플랜을 만들어서 서브에이전트가 각 태스크를 처리하는 방식이에요.
