### 1. NPM 설치
``` bash
npm install -g @openai/codex
```

### 2. 플러그인 설치
###### *claude 실행 후 아래 명령어들 실행*
``` claude
1. Claude Code 플러그인 마켓플레이스에서 추가
/plugin marketplace add openai/codex-plugin-cc

2. 플러그인 설치
/plugin install codex@openai-codex

3. 플러그인 재로드
/reload-plugins

4. 설정 확인 및 로그인
/codex:setup
```


##### 3. 사용
####### *클로드 안에서*
``` 
/codex: 후 해당 명령어
```
