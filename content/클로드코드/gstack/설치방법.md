잠깐 확인해볼게요.gstack는 MCP가 아니라 **Claude Code 슬래시 커맨드 기반 스킬팩**이에요. Y Combinator CEO Garry Tan이 오픈소스로 공개한 거고요.

## gstack이 뭔지

코드 생성만 하는 기존 툴과 달리, `/plan-ceo-review`, `/plan-eng-review`, `/review`, `/ship`, `/qa`, `/retro` 등으로 기획부터 QA, 회고까지 전체 개발 라이프사이클을 커버해요.

CEO, Designer, Eng Manager, Release Manager, Doc Engineer, QA 역할을 하는 23개 전문 스킬과 8개 파워툴을 슬래시 커맨드로 패키징한 거예요.

## 설치

```bash
# 저장소 클론
git clone https://github.com/garrytan/gstack
cd gstack

# 설치
./setup

# 팀 단위 설치 (세션 시작 시 자동 업데이트)
./setup --team
```


## Claude Code 연동

설치 후 프로젝트의 `CLAUDE.md`에 gstack 섹션 추가하면 돼요:

```markdown
## gstack
Use /browse from gstack for all web browsing.
Never use mcp__claude-in-chrome__* tools.
```

Claude Code가 스킬을 못 찾는다고 하면 CLAUDE.md에 gstack 섹션이 있는지 확인하면 돼요.

Go 백엔드 프로젝트에 쓰면 `/plan-eng-review`로 아키텍처 검토하고, `/review`로 코드 리뷰, `/ship`으로 배포까지 자동화하는 흐름이 잘 맞을 것 같아요.
