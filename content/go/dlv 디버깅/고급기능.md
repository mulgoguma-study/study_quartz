### DLV (Delve) 고급 기능 설명

DLV(Delve)는 Go 프로그램 디버깅을 위한 강력한 도구로, 기본 명령어(예: `next`, `step`, `print`) 외에 고급 기능을 통해 복잡한 시나리오를 처리할 수 있습니다. 아래는 2025년 기준 DLV CLI 문서에서 추출한 주요 고급 기능 목록입니다. 각 기능에 간단한 설명, 사용 예시를 포함했습니다. 이 기능들은 원격 디버깅(예: GoLand 연동)에서도 활용 가능하며, DLV 버전 1.25 이상에서 안정적으로 지원됩니다.

#### 1. **조건부 브레이크포인트 (Conditional Breakpoints)**
   - **설명**: 브레이크포인트가 특정 조건(예: 변수 값, 히트 횟수)을 만족할 때만 실행되도록 설정. Go루틴(goroutine)별 히트 카운트도 지원.
   - **사용 예시**: `break main.go:55 if i == 5` (55번째 줄에서 i가 5일 때만 멈춤) 또는 `condition <breakpoint_id> <조건식>`.
   - **팁**: 히트 카운트 조건: `condition -hitcount bp > 5`.

#### 2. **트레이스포인트 (Tracepoints)**
   - **설명**: 프로그램을 멈추지 않고 히트 시 로그만 출력하는 가벼운 브레이크포인트. 성능 오버헤드가 적어 프로덕션-like 디버깅에 유용.
   - **사용 예시**: `trace main.main` (main 함수 진입 시 로그 출력) 또는 `condition <trace_id> <조건>`으로 조건 추가.
   - **팁**: `on <trace> trace`로 브레이크포인트를 트레이스포인트로 변환.

#### 3. **워치포인트 (Watchpoints)**
   - **설명**: 메모리 위치(변수나 포인터)의 읽기/쓰기 접근을 감시하고, 접근 시 프로그램을 멈춤. 값 변경이 없을 때는 감지되지 않을 수 있음.
   - **사용 예시**: `watch -w *(*int)(0x1400007c018)` (지정 메모리 쓰기 감시) 또는 `watch v` (변수 v 감시).
   - **팁**: 옵션: `-r` (읽기), `-w` (쓰기), `-rw` (둘 다).

#### 4. **역방향 디버깅 (Reverse Debugging)**
   - **설명**: 프로그램 상태를 기록해 앞으로/뒤로 스텝 실행. 버그 재현이 어려운 경우 유용한 '시간 여행' 기능.
   - **사용 예시**: `rev next` (역방향 next), `rewind` (브레이크포인트까지 역방향 실행).
   - **팁**: 기록된 히스토리 시작까지 rewind 가능.

#### 5. **체크포인트 (Checkpoints)**
   - **설명**: 현재 프로그램 상태를 스냅샷으로 저장. 나중에 해당 지점으로 되돌아가거나 재실행.
   - **사용 예시**: `checkpoint [노트]` (생성), `checkpoints` (목록), `restart <checkpoint_id>` (재시작).
   - **팁**: 역방향 디버깅과 결합 시 강력.

#### 6. **로그/트랜스크립트 (Logging / Transcript)**
   - **설명**: 디버깅 세션을 파일로 기록. 명령 출력과 타임스탬프를 포함해 재분석 용이.
   - **사용 예시**: `transcript output.log` (시작), `transcript -off` (중지).
   - **팁**: `-t` (타임스탬프), `-x` (XML 형식) 옵션.

#### 7. **브레이크포인트 액션 (On-Breakpoint Commands)**
   - **설명**: 브레이크포인트 히트 시 자동으로 명령(예: print, stack) 실행. Starlark 스크립트도 지원.
   - **사용 예시**: `on <bp_id> print x` (x 변수 출력), `on <bp_id> -edit` (액션 수정).
   - **팁**: `on <bp> trace`로 트레이스포인트 변환.

#### 8. **지연 호출 컨텍스트 실행 (Deferred Call Context Execution)**
   - **설명**: defer 함수 호출 컨텍스트에서 명령 실행. 지연 호출의 로컬/인자 검사에 유용.
   - **사용 예시**: `deferred 0 print locals` (첫 번째 defer에서 로컬 변수 출력).
   - **팁**: `deferred-calls`로 defer 목록 확인.

#### 9. **함수 호출 주입 (Function Call Injection) - 실험적**
   - **설명**: 실행 중 함수를 주입해 테스트. Linux 네이티브 백엔드에서만 동작하며, 스택 공간과 안전 지점이 필요.
   - **사용 예시**: `call -unsafe myFunc(42)` (myFunc(42) 호출).
   - **팁**: 런타임 실행 중 goroutine에서는 제한됨. 2025년 기준 EXPERIMENTAL.

#### 10. **스택 트레이스 모드 (Stack Trace Modes)**
    - **설명**: 스택 출력을 커스터마이징. ancestor 트레이스나 defer 포함 출력 지원.
    - **사용 예시**: `stack -mode fromg` (goroutine 중심), `stack -a 5` (상위 5개 ancestor).
    - **팁**: 모드: `normal`, `simple`, `fromg`.

#### 11. **고루틴 필터링/그루핑/실행 (Goroutine Filtering, Grouping, and Execution)**
    - **설명**: 고루틴을 필터링/그룹화하고, 그룹 전체에 명령 실행. 복잡한 동시성 디버깅에 필수.
    - **사용 예시**: `goroutines -group userloc -exec print x` (사용자 위치 그룹에서 x 출력).
    - **팁**: `-with running` (실행 중인 고루틴 필터).

#### 12. **Starlark 스크립팅 (Starlark Scripting)**
    - **설명**: Starlark(파이썬-like 스크립트 언어)로 자동화 스크립트 작성. 브레이크포인트 액션에 통합.
    - **사용 예시**: `source script.star` (스크립트 로드), `source -` (REPL 모드).
    - **팁**: `on` 명령과 결합해 복잡한 워크플로 자동화.

#### 13. **프로세스 기록 및 체크포인트 재시작 (Process Recording and Restart)**
    - **설명**: 프로세스 상태를 기록하고, 체크포인트나 시작점에서 재시작. 인자/I/O 리디렉션 제어.
    - **사용 예시**: `restart -r newargs...` (새 인자로 재기록).
    - **팁**: 역방향 디버깅의 확장.

**추가 팁**:
- 이 기능들은 DLV의 `--api-version=2` (기본)에서 잘 동작하며, GoLand의 DLV 통합에서 대부분 지원됩니다.
- 실험적 기능(예: 함수 주입)은 안정성 확인 후 사용하세요. 더 자세한 예시는 DLV 문서(`dlv help <command>`)나 GitHub에서 확인.
- 문제 발생 시: `dlv --log`으로 로그 활성화.

이 기능들로 더 세밀한 디버깅이 가능할 거예요. 특정 기능에 대한 예제 코드가 필요하시면 말씀해주세요!
