atlas에서 추출한 PostgreSQL 스키마를 ent 스키마로 변환하는 범용 코드를 작성해드리겠습니다.이 코드는 Atlas에서 추출한 PostgreSQL 스키마를 ent 스키마로 자동 변환해줍니다.

## 주요 기능

1. **자동 타입 매핑**: PostgreSQL 타입을 ent 필드 타입으로 자동 변환
2. **인덱스 처리**: unique 인덱스와 일반 인덱스 자동 생성
3. **Nullable 처리**: null 가능 컬럼을 Optional()로 변환
4. **Default 값**: 기본값 자동 설정

## 사용 방법

```bash
# 1. Atlas로 스키마 추출
atlas schema inspect -u "postgres://user:pass@localhost:5432/dbname?sslmode=disable" --format '{{ json . }}' > schema.json

# 2. 코드 실행
go run main.go schema.json ./ent/schema

# 3. 생성된 파일에서 Edges() 함수에 관계 추가
# 4. ent 코드 생성
go generate ./ent
```

## 예시 출력

예를 들어 `users` 테이블이 있다면:

- `user.go` 파일이 생성됨
- 모든 필드가 자동으로 ent 형태로 변환
- Edges() 함수에 TODO 주석으로 관계 추가할 위치 표시

관계(relationship)와 외래키는 생성된 파일의 `Edges()` 함수에 수동으로 추가하시면 됩니다!

``` go
package main

import (
	"encoding/json"
	"fmt"
	"os"
	"path/filepath"
	"strings"
	"text/template"
)

// Atlas 실제 스키마 구조 (schemas 배열 포함)
type AtlasSchema struct {
	Schemas []Schema `json:"schemas"`
}

type Schema struct {
	Name   string  `json:"name"`
	Tables []Table `json:"tables"`
}

type Table struct {
	Name    string   `json:"name"`
	Columns []Column `json:"columns"`
	Indexes []Index  `json:"indexes,omitempty"`
}

type Column struct {
	Name     string `json:"name"`
	Type     string `json:"type"`
	Nullable bool   `json:"null,omitempty"`
	Default  string `json:"default,omitempty"`
}

type Index struct {
	Name    string   `json:"name"`
	Unique  bool     `json:"unique,omitempty"`
	Columns []string `json:"columns"`
}

// Ent 스키마 생성을 위한 구조
type EntSchema struct {
	TableName  string
	StructName string
	Fields     []EntField
	Indexes    []EntIndex
}

type EntField struct {
	Name         string
	Type         string
	GoType       string
	Optional     bool
	Default      string
	Unique       bool
	IsForeignKey bool
}

type EntIndex struct {
	Name    string
	Unique  bool
	Columns []string
}

const entTemplate = `package schema

import (
	"time"

	"entgo.io/ent"
	"entgo.io/ent/schema"
	"entgo.io/ent/schema/field"
{{- if .Indexes}}
	"entgo.io/ent/schema/index"
{{- end}}
)

// {{.StructName}} holds the schema definition for the {{.StructName}} entity.
type {{.StructName}} struct {
	ent.Schema
}

// Annotations of the {{.StructName}}.
func ({{.StructName}}) Annotations() []schema.Annotation {
	return []schema.Annotation{
		schema.Table("{{.TableName}}"),
	}
}

// Fields of the {{.StructName}}.
func ({{.StructName}}) Fields() []ent.Field {
	return []ent.Field{
{{- range .Fields}}
{{- if .IsForeignKey}}
		// Foreign key field - consider using Edge instead
{{- end}}
		field.{{.Type}}("{{.Name}}"){{if .Optional}}.
			Optional(){{end}}{{if .Default}}.
			Default({{.Default}}){{if eq .Default "time.Now"}}.
			Immutable(){{end}}{{end}}{{if .Unique}}.
			Unique(){{end}},
{{- end}}
	}
}

// Edges of the {{.StructName}}.
func ({{.StructName}}) Edges() []ent.Edge {
	return []ent.Edge{
		// TODO: Add edges (relationships) here
		// Detected possible foreign keys:
{{- range .Fields}}
{{- if .IsForeignKey}}
		// - {{.Name}}: Consider adding edge relationship
{{- end}}
{{- end}}
		//
		// Examples:
		// edge.To("teams", Team.Type),           // One-to-Many
		// edge.From("comp", Comp.Type).          // Many-to-One
		//     Ref("teams").
		//     Unique(),
	}
}
{{- if .Indexes}}

// Indexes of the {{.StructName}}.
func ({{.StructName}}) Indexes() []ent.Index {
	return []ent.Index{
{{- range .Indexes}}
		index.Fields({{range $i, $col := .Columns}}{{if $i}}, {{end}}"{{$col}}"{{end}}){{if .Unique}}.
			Unique(){{end}},
{{- end}}
	}
}
{{- end}}
`

func main() {
	if len(os.Args) < 3 {
		fmt.Println("Usage: go run main.go <atlas-schema.json> <output-dir>")
		fmt.Println("Example: go run main.go schema.json ./ent/schema")
		os.Exit(1)
	}

	inputFile := os.Args[1]
	outputDir := os.Args[2]

	fmt.Printf("📖 Reading file: %s\n", inputFile)

	// JSON 파일 읽기
	data, err := os.ReadFile(inputFile)
	if err != nil {
		fmt.Printf("❌ Error reading file: %v\n", err)
		os.Exit(1)
	}

	var atlasSchema AtlasSchema
	if err := json.Unmarshal(data, &atlasSchema); err != nil {
		fmt.Printf("❌ Error parsing JSON: %v\n", err)
		os.Exit(1)
	}

	if len(atlasSchema.Schemas) == 0 {
		fmt.Println("❌ No schemas found in JSON")
		os.Exit(1)
	}

	fmt.Printf("✅ Found %d schema(s)\n", len(atlasSchema.Schemas))

	// 출력 디렉토리 생성
	if err := os.MkdirAll(outputDir, 0755); err != nil {
		fmt.Printf("❌ Error creating output directory: %v\n", err)
		os.Exit(1)
	}

	// 템플릿 파싱
	tmpl, err := template.New("ent").Parse(entTemplate)
	if err != nil {
		fmt.Printf("❌ Error parsing template: %v\n", err)
		os.Exit(1)
	}

	totalTables := 0
	// 각 스키마의 테이블 처리
	for _, schema := range atlasSchema.Schemas {
		fmt.Printf("\n🔍 Processing schema: %s (%d tables)\n", schema.Name, len(schema.Tables))

		for _, table := range schema.Tables {
			totalTables++
			entSchema := convertToEntSchema(table)

			// 파일명 생성
			fileName := strings.ToLower(entSchema.StructName) + ".go"
			filePath := filepath.Join(outputDir, fileName)

			// 파일 생성
			f, err := os.Create(filePath)
			if err != nil {
				fmt.Printf("  ❌ Error creating file %s: %v\n", fileName, err)
				continue
			}

			// 템플릿 실행
			if err := tmpl.Execute(f, entSchema); err != nil {
				fmt.Printf("  ❌ Error executing template for %s: %v\n", fileName, err)
				f.Close()
				continue
			}

			f.Close()
			
			// 외래키 탐지 정보 출력
			fkCount := 0
			for _, field := range entSchema.Fields {
				if field.IsForeignKey {
					fkCount++
				}
			}
			
			if fkCount > 0 {
				fmt.Printf("  ✅ Created: %s (%d fields, %d possible FKs)\n", fileName, len(entSchema.Fields), fkCount)
			} else {
				fmt.Printf("  ✅ Created: %s (%d fields)\n", fileName, len(entSchema.Fields))
			}
		}
	}

	fmt.Printf("\n🎉 Conversion completed! Generated %d files\n", totalTables)
	fmt.Println("\n📝 Next steps:")
	fmt.Println("1. Review generated files in:", outputDir)
	fmt.Println("2. Check Edges() functions for foreign key hints")
	fmt.Println("3. Add proper edge relationships (edge.To/edge.From)")
	fmt.Println("4. Run: go generate ./ent")
}

func convertToEntSchema(table Table) EntSchema {
	schema := EntSchema{
		TableName:  table.Name,
		StructName: toPascalCase(table.Name),
		Fields:     make([]EntField, 0),
		Indexes:    make([]EntIndex, 0),
	}

	// 컬럼 변환
	for _, col := range table.Columns {
		// idx, id 필드는 스킵 (ent가 자동 생성)
		lowerName := strings.ToLower(col.Name)
		if lowerName == "idx" || lowerName == "id" {
			continue
		}

		lowerName := strings.ToLower(col.Name)
		
		// created_at, updated_at은 nullable이어도 Optional 제거하고 Default(time.Now) 사용
		isTimestampField := lowerName == "created_at" || lowerName == "updated_at"
		
		field := EntField{
			Name:         col.Name,
			Type:         mapPostgresTypeToEnt(col.Type),
			GoType:       mapPostgresTypeToGo(col.Type),
			Optional:     col.Nullable && !isTimestampField, // timestamp 필드는 Optional 제거
			IsForeignKey: isForeignKeyField(col.Name),
		}

		// Default 값 설정
		if col.Default != "" {
			field.Default = formatDefault(col.Default, col.Type, col.Name)
		} else if isTimestampField {
			// created_at, updated_at은 자동으로 time.Now 설정
			field.Default = "time.Now"
		} else if !col.Nullable {
			// nullable이 아니고 default가 없는 경우 기본값 추가
			field.Default = getDefaultValue(col.Type)
		}

		schema.Fields = append(schema.Fields, field)
	}

	// 인덱스 변환
	for _, idx := range table.Indexes {
		// Primary key는 스킵
		if strings.Contains(strings.ToLower(idx.Name), "pkey") {
			continue
		}

		// idx 컬럼은 제외
		filteredCols := make([]string, 0)
		for _, col := range idx.Columns {
			if strings.ToLower(col) != "idx" && strings.ToLower(col) != "id" {
				filteredCols = append(filteredCols, col)
			}
		}

		if len(filteredCols) > 0 {
			entIdx := EntIndex{
				Name:    idx.Name,
				Unique:  idx.Unique,
				Columns: filteredCols,
			}
			schema.Indexes = append(schema.Indexes, entIdx)
		}
	}

	return schema
}

// 외래키로 추정되는 필드인지 확인
func isForeignKeyField(fieldName string) bool {
	lowerName := strings.ToLower(fieldName)
	// _idx, _id로 끝나는 필드는 외래키로 추정
	return strings.HasSuffix(lowerName, "_idx") || 
	       strings.HasSuffix(lowerName, "_id") ||
	       lowerName == "comp_idx" ||
	       lowerName == "team_idx" ||
	       lowerName == "user_idx"
}

func mapPostgresTypeToEnt(pgType string) string {
	pgType = strings.ToLower(pgType)

	switch {
	case strings.Contains(pgType, "character varying"), strings.Contains(pgType, "varchar"):
		return "String"
	case strings.Contains(pgType, "text"):
		return "Text"
	case strings.Contains(pgType, "bigint"), strings.Contains(pgType, "int8"):
		return "Int64"
	case strings.Contains(pgType, "integer"), strings.Contains(pgType, "int4"):
		return "Int"
	case strings.Contains(pgType, "smallint"), strings.Contains(pgType, "int2"):
		return "Int16"
	case strings.Contains(pgType, "boolean"), strings.Contains(pgType, "bool"):
		return "Bool"
	case strings.Contains(pgType, "timestamp without time zone"), strings.Contains(pgType, "timestamp"):
		return "Time"
	case strings.Contains(pgType, "date"):
		return "Time"
	case strings.Contains(pgType, "numeric"), strings.Contains(pgType, "decimal"):
		return "Float64"
	case strings.Contains(pgType, "double precision"), strings.Contains(pgType, "float8"):
		return "Float64"
	case strings.Contains(pgType, "real"), strings.Contains(pgType, "float4"):
		return "Float"
	case strings.Contains(pgType, "uuid"):
		return "UUID"
	case strings.Contains(pgType, "json"), strings.Contains(pgType, "jsonb"):
		return "JSON"
	case strings.Contains(pgType, "bytea"):
		return "Bytes"
	default:
		fmt.Printf("  ⚠️  Unknown type: %s, using String\n", pgType)
		return "String"
	}
}

func mapPostgresTypeToGo(pgType string) string {
	pgType = strings.ToLower(pgType)

	switch {
	case strings.Contains(pgType, "character varying"), strings.Contains(pgType, "text"), strings.Contains(pgType, "varchar"):
		return "string"
	case strings.Contains(pgType, "bigint"), strings.Contains(pgType, "int8"):
		return "int64"
	case strings.Contains(pgType, "integer"), strings.Contains(pgType, "int4"):
		return "int"
	case strings.Contains(pgType, "smallint"), strings.Contains(pgType, "int2"):
		return "int16"
	case strings.Contains(pgType, "boolean"), strings.Contains(pgType, "bool"):
		return "bool"
	case strings.Contains(pgType, "timestamp"), strings.Contains(pgType, "date"):
		return "time.Time"
	case strings.Contains(pgType, "numeric"), strings.Contains(pgType, "decimal"), strings.Contains(pgType, "float"):
		return "float64"
	case strings.Contains(pgType, "uuid"):
		return "uuid.UUID"
	default:
		return "string"
	}
}

func formatDefault(defaultVal, pgType string, fieldName string) string {
	if defaultVal == "" {
		return ""
	}

	pgType = strings.ToLower(pgType)
	defaultVal = strings.TrimSpace(defaultVal)

	// 시간 타입 - now() 함수 또는 created_at/updated_at 필드
	if strings.Contains(pgType, "timestamp") || strings.Contains(pgType, "date") {
		lowerFieldName := strings.ToLower(fieldName)
		if strings.Contains(strings.ToLower(defaultVal), "now()") || 
		   strings.Contains(strings.ToLower(defaultVal), "current_timestamp") ||
		   lowerFieldName == "created_at" ||
		   lowerFieldName == "updated_at" {
			return "time.Now"
		}
	}

	// 문자열 타입
	if strings.Contains(pgType, "varchar") || strings.Contains(pgType, "text") || strings.Contains(pgType, "character") {
		cleaned := strings.Trim(defaultVal, "'\"")
		return fmt.Sprintf(`"%s"`, cleaned)
	}

	// 불린 타입
	if strings.Contains(pgType, "bool") {
		if strings.ToLower(defaultVal) == "true" || defaultVal == "1" {
			return "true"
		}
		return "false"
	}

	// 숫자 타입
	if strings.Contains(pgType, "int") || strings.Contains(pgType, "numeric") || strings.Contains(pgType, "float") {
		// 숫자에서 불필요한 문자 제거
		cleaned := strings.Trim(defaultVal, "'\"")
		return cleaned
	}

	return ""
}

// nullable이 아닌 필드에 대한 기본 기본값
func getDefaultValue(pgType string) string {
	pgType = strings.ToLower(pgType)

	switch {
	case strings.Contains(pgType, "timestamp"), strings.Contains(pgType, "date"):
		return "time.Now"
	case strings.Contains(pgType, "bool"):
		return "false"
	case strings.Contains(pgType, "int"):
		return "0"
	case strings.Contains(pgType, "float"), strings.Contains(pgType, "numeric"), strings.Contains(pgType, "decimal"):
		return "0.0"
	case strings.Contains(pgType, "varchar"), strings.Contains(pgType, "text"), strings.Contains(pgType, "character"):
		return `""`
	default:
		return ""
	}
}

func toPascalCase(s string) string {
	// tb_, tbl_ 접두사 제거
	s = strings.TrimPrefix(s, "tb_")
	s = strings.TrimPrefix(s, "tbl_")

	// 언더스코어로 분리
	parts := strings.Split(s, "_")
	for i, part := range parts {
		if len(part) > 0 {
			parts[i] = strings.ToUpper(part[:1]) + strings.ToLower(part[1:])
		}
	}
	return strings.Join(parts, "")
}
```
