# Phase 3 Guide: Working with Images

## Tensor Layouts (NCHW vs NHWC)
Deep learning models typically expect image data in 4D tensors.
*   **N**: Batch Size (number of images)
*   **C**: Channels (e.g., 3 for RGB, 1 for Grayscale)
*   **H**: Height
*   **W**: Width

ONNX (and PyTorch) usually defaults to **NCHW**.
TensorFlow/Keras sometimes defaults to **NHWC**.
Always check your model's requirement! The `mnist.onnx` generated by PyTorch expects **NCHW** (`[Batch, Channel, Height, Width]`).

## Flattening Data
Go's slice is 1D. To represent a 4D tensor, you must flatten the data.
For NCHW, the order is:
1.  Pixel (0,0) of Channel 0, Image 0
2.  Pixel (0,1) of Channel 0, Image 0
...
3.  Pixel (H, W) of Channel C, Image N

If you use an image library to load a PNG, you generally iterate `y` from 0 to Height, `x` from 0 to Width, extract the color value, normalize it (usually 0.0 to 1.0 or -1.0 to 1.0), and append to your slice.

## Preprocessing
The model expects specific normalization.
*   **MNIST**: Usually 0.0 to 1.0 (Black to White) or standardized `(pixel - 0.1307) / 0.3081`. 
*   **ImageNet**: Usually Normalized using mean/std for R, G, B channels.

If you don't match the training preprocessing, your results will be garbage!

## Post-processing
The output is often a vector of scores (logits) or probabilities (softmax).
*   **Logits**: Raw scores, can be negative. Higher is better.
*   **Softmax**: Probabilities summing to 1.0.

To find the class, you simply find the index of the maximum value (`ArgMax`).
