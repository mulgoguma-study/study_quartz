연동만 하는거라 그냥 도커가 공식문서에서 권장되는 방식이라 이걸로 함.
설정은 livekit.yaml을 건드는 방식

1. livekit.yaml
	``` yaml
	# livekit.yaml
port: 7880
rtc:
  # 운영 환경에서는 UDP 포트 범위를 열어줘야 합니다.
  port_range_start: 50000
  port_range_end: 60000
  use_external_ip: false # 클라우드 환경(AWS 등)이라면 true, 내부면 false
  # 아래 조건 중 하나라도 해당되면 true로 변경:
  # 1. AWS/Google Cloud/Azure 사용 중
  # 2. 공인 IP가 있고 외부 접속 필요
  # 3. Docker/Kubernetes에서 hostNetwork 사용
  # 4. STUN 서버를 통해 외부 IP 확인 필요

keys:
  # API_KEY: API_SECRET 형식
  my_api_key: "your_strong_secret_key_here"

logging:
  level: info
	```

2. docker-compose.yaml
   ``` yaml
   version: '3'
services:
  livekit:
    image: livekit/livekit-server:latest
    container_name: livekit-server
    restart: unless-stopped
    # webrtc는 레이턴시문제로 bridge보다 host 추천.
    network_mode: "host"   
    volumes:
      - ./livekit.yaml:/livekit.yaml
    command: --config /livekit.yaml
   ```

3. 컨테이너 실행
   ``` bash
   docker compose up -d
   ```

4. 로그 확인 
	1. ``` bash
	   docker logs -f livekit-server
	   ```

추가 확인사항
- **SSL 적용:** 실제 운영에서는 `7880` 포트에 직접 연결하기보다, 앞단에 **Nginx**나 **Caddy** 같은 리버스 프록시를 두어 HTTPS(SSL)를 적용하는 것이 필수입니다.
    
- **고정 IP:** 만약 서버가 재시작될 때 IP가 바뀐다면 클라이언트 연결이 끊길 수 있으니, 클라우드라면 **Elastic IP(고정 IP)**를 할당하세요.
