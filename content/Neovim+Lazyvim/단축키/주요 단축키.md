#### 코드 정의(Definition) 이동
기본적으로 **LSP(Language Server Protocol)** 기능이 활성화되어 있기 때문에 단축키 하나로 해결


##### 핵심 단축키

코드 위에 커서를 올리고 다음 키를 누르세요.

- **`gd`**: **Go to Definition** (가장 많이 사용)
    
    - 현재 창에서 해당 심볼이 정의된 곳으로 이동합니다.
        
- **`ctrl-위화살표`** 또는 **`ctrl-o`**: **이전 위치로 돌아오기**
    
    - 정의를 확인한 후 원래 코딩하던 곳으로 점프해서 돌아올 때 필수입니다.


|**기능**|**단축키**|**설명**|
|---|---|---|
|**정의 미리보기**|`gD` (대문자)|새 창으로 이동하지 않고 작은 팝업(Floating Window)으로 정의를 보여줍니다.|
|**수평 분할 이동**|`ctrl-w v` 후 `gd`|화면을 옆으로 가르고 정의로 이동합니다. (LazyVim 기본 설정에 따라 `gD`가 이 역할을 하기도 합니다.)|
|**새 탭에서 열기**|`ctrl-w g d`|새로운 탭 페이지에서 정의를 엽니다.|


##### 창 나눈후
###### 1. 기본 이동 단축키 (가장 권장)

LazyVim에는 `vim-illuminate`나 내장 설정 덕분에 별도의 접두사 없이 바로 이동할 수 있는 매핑이 되어 있습니다.

- **`Ctrl` + `h`**: 왼쪽 창으로 이동
    
- **`Ctrl` + `j`**: 아래쪽 창으로 이동
    
- **`Ctrl` + `k`**: 위쪽 창으로 이동
    
- **`Ctrl` + `l`**: 오른쪽 창으로 이동
    

> [!NOTE] 만약 터미널 환경 설정에 따라 `Ctrl` 조합이 안 먹는다면, 전통적인 방식인 **`Ctrl` + `w`**를 누른 뒤 방향키(`h`, `j`, `k`, `l`)를 눌러보세요.

---

###### 2. 창 관리에 유용한 추가 단축키

창을 이동하는 것 외에 분할된 창을 조절할 때 자주 쓰이는 LazyVim 기본 단축키들입니다.

|기능|단축키|비고|
|---|---|---|
|**창 닫기**|`<Leader>wd`|현재 포커스된 창을 닫습니다. (`:q`와 동일)|
|**수직 분할**|`<Leader>wv`|창을 세로로 나눕니다.|
|**수평 분할**|`<Leader>ws`|창을 가로로 나눕니다.|
|**창 크기 조절**|`Ctrl` + `화살표`|현재 창의 크기를 미세하게 조정합니다.|
