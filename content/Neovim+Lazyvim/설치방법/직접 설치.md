리눅스 버전 때문에 apt install neovim 이 너무 예전 버전으로 설치될때 아래 방법

## 1. Node.js 설치 (Neovim 플러그인 의존성)

bash

```bash
# nvm으로 설치 권장
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc

nvm install --lts
nvm use --lts
node --version
```


# 2. 사전설치
```bash
sudo dnf update -y
sudo dnf install -y git curl wget unzip gcc make ripgrep fd-find
```


# 3. Neovim 설치
```bash
## 최신 stable 다운로드
wget https://github.com/neovim/neovim/releases/download/v0.10.0/nvim-linux64.tar.gz
tar xzf nvim-linux64.tar.gz

## 시스템에 설치
sudo mv nvim-linux64 /opt/nvim
sudo ln -sf /opt/nvim/bin/nvim /usr/local/bin/nvim

## 확인
nvim --version
```
