Rust의 Cargo는 프로젝트의 파일 구조를 표준화하고 관리하는 데 중요한 역할을 합니다. Cargo를 사용하여 생성된 Rust 프로젝트는 다음과 같은 기본적인 파일 및 디렉토리 구조를 가집니다.

기본 파일 및 디렉토리 구조:

    Cargo.toml:
        프로젝트의 메타데이터와 의존성을 정의하는 파일입니다.
        프로젝트 이름, 버전, 작성자, 의존성 라이브러리 목록 등이 포함됩니다.
    src/:
        Rust 소스 코드가 위치하는 디렉토리입니다.
        src/main.rs:
            실행 가능한 바이너리 프로젝트의 진입점(entry point)입니다.
        src/lib.rs:
            라이브러리 프로젝트의 진입점입니다.
    target/:
        빌드 결과물이 저장되는 디렉토리입니다.
        컴파일된 실행 파일, 라이브러리, 디버그 정보 등이 포함됩니다.
        target/debug:
            디버그 모드로 빌드된 결과물이 저장됩니다.
        target/release:
            릴리스 모드로 빌드된 결과물이 저장됩니다.

Cargo 관련 주요 명령어:

    cargo new <프로젝트_이름>:
        새로운 Rust 프로젝트를 생성합니다.
    cargo build:
        프로젝트를 컴파일합니다.
    cargo run:
        프로젝트를 빌드하고 실행합니다.
    cargo check:
        코드가 컴파일 될 수 있는지 확인 합니다.
    cargo test:
        테스트 코드들을 실행 합니다.
    cargo add <라이브러리_이름>:
        Cargo.toml에 새로운 라이브러리 의존성을 추가합니다.

추가 정보:

    Cargo는 의존성 관리, 빌드 자동화, 테스트 실행 등 다양한 기능을 제공하여 Rust 프로젝트 개발을 효율적으로 만들어줍니다.
    Cargo.toml 파일은 프로젝트의 모든 의존성을 중앙에서 관리하므로, 프로젝트의 의존성을 쉽게 추적하고 업데이트할 수 있습니다.
    Cargo workspaces는 여러개의 관련된 패키지들을 관리하는 기능을 제공합니다.
