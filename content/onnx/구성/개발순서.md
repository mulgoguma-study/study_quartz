## 실제 개발 순서

```
Engine (저수준) → Session → Buffer → Processor → Pool (고수준)
```

**이유**: 의존성이 아래에서 위로 올라가기 때문입니다.

### 3단계: Buffer (메모리 관리)

```go
// buffer/tensor_buffer.go
package buffer

import "sync"

type TensorBuffer struct {
    pool      sync.Pool
    shape     []int64
    totalSize int
}

func NewTensorBuffer(shape []int64) *TensorBuffer {
    totalSize := 1
    for _, dim := range shape {
        totalSize *= int(dim)
    }
    
    return &TensorBuffer{
        shape:     shape,
        totalSize: totalSize,
        pool: sync.Pool{
            New: func() interface{} {
                return make([]float32, totalSize)
            },
        },
    }
}

func (b *TensorBuffer) Get() []float32 {
    return b.pool.Get().([]float32)
}

func (b *TensorBuffer) Put(data []float32) {
    // 재사용을 위해 0으로 초기화
    for i := range data {
        data[i] = 0
    }
    b.pool.Put(data)
}
```

**테스트**: 메모리 재사용 및 누수 확인

### 4단계: Processor (전/후처리 로직)

type ImageProcessor struct {
    buffer     *buffer.TensorBuffer

    return &ImageProcessor{
        buffer:     buffer.NewTensorBuffer(shape),
        inputShape: shape,
        mean:       []float32{0.485, 0.456, 0.406}, // ImageNet
        std:        []float32{0.229, 0.224, 0.225},
    }
}

    tensorData := p.buffer.Get()
    defer p.buffer.Put(tensorData)

        return nil, err

    resized := resize(img, int(p.inputShape[2]), int(p.inputShape[3]))
    normalized := p.normalize(resized)
    
    return normalized, nil
}

### 5단계: Pool (동시성 관리)

```go
// pool/session_pool.go
package pool

import (
    "sync"
    "myproject/session"
    "myproject/processor"
)

type SessionPool struct {
    sessions   chan *session.ModelSession
    processor  *processor.ImageProcessor
    maxSessions int
}

func NewSessionPool(modelPath string, maxSessions int) (*SessionPool, error) {
    pool := &SessionPool{
        sessions:    make(chan *session.ModelSession, maxSessions),
        maxSessions: maxSessions,
    }
    
    // 세션 미리 생성
    for i := 0; i < maxSessions; i++ {
        sess, err := session.NewSession(engine, modelPath)
        if err != nil {
            return nil, err
        }
        pool.sessions <- sess
    }
    
    // Processor 초기화
    pool.processor = processor.NewImageProcessor(sess.inputShape)
    
    return pool, nil
}

func (p *SessionPool) Infer(imageBytes []byte) (interface{}, error) {
    // 1. 세션 획득
    sess := <-p.sessions
    defer func() { p.sessions <- sess }()
    
    // 2. 전처리
    inputData, err := p.processor.Preprocess(imageBytes)
    if err != nil {
        return nil, err
    }
    
    // 3. 추론
    output, err := sess.Run(inputData)
    if err != nil {
        return nil, err
    }
    
    // 4. 후처리
    result := p.processor.Postprocess(output)
    
    return result, nil
}
```

**테스트**: 동시 요청 부하 테스트

## 실전 개발 팁

```go
// main.go - 전체 통합 테스트
func main() {
    // 1. Engine 초기화
    engine, _ := engine.NewEngine()
    defer engine.Close()
    
    // 2. Pool 생성 (내부적으로 Session, Buffer, Processor 생성)
    pool, _ := pool.NewSessionPool("model.onnx", 4)
    
    // 3. 추론
    imageBytes, _ := os.ReadFile("test.jpg")
    result, _ := pool.Infer(imageBytes)
    
    fmt.Printf("Result: %v\n", result)
}
```

**각 단계별 체크포인트**:

- ✅ Engine: 모델 로드 성공
- ✅ Session: 단일 추론 성공
- ✅ Buffer: 메모리 누수 없음
- ✅ Processor: 전/후처리 정확도
- ✅ Pool: 동시성 안정성

이렇게 **Bottom-up**으로 개발하면서 각 단계를 검증하는 게 가장 안전합니다!
